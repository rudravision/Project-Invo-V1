# Templates

These files are intentionally empty of real acquisition data. Copy them into `CIVLIB/00_Admin/` after running the bootstrap helper, remove the `EXAMPLE-DO-NOT-KEEP` rows, and preserve them as auditable operational records.

- `acquisition-ledger.csv` is one row per acquired file, not merely one row per web site.
- `rag-allowlist.csv` is a narrow, explicit subset. It is not a list of everything locally searchable.
- `rights-review-checklist.md` is completed before changing a document's RAG state.
- `rag-answer-contract.md` is the required visible evidence/synthesis/uncertainty format for any local RAG interface.
- `partition-record.md`, `verification-log.csv`, `replacement-schedule.csv`, and `hardware-inventory.csv` support long-term recovery.
- `emergency-contacts-template.md` should be filled with local, time-sensitive information and printed.
- `recovery-quick-guide.md` is a print-ready “clone first” guardrail; fill its device-specific blanks after recovery drills.
